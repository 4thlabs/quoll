# Quoll

Header-only C++20 framework for cross-platform applications: a sans-IO async runtime, HTTP client and server, and a
typed API DSL whose TypeScript side is a stock [tRPC](https://trpc.io/) client. Write the UI once with web
technologies and deploy the same application as a native server + web app, a standalone PWA (core in WASM) or a native
webview shell.

**Status: exploration.** Nothing is usable yet; see [`docs/PLAN.md`](docs/PLAN.md) for the design.
